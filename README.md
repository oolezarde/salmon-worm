# 鮭魚蟲餵養計畫

鼠鼠從一顆發眼卵開始養鮭魚，養大以後放進大海存起來，想吃的時候去下雪的河口釣，釣起來的送進 −35°C 的冷鏈倉，再一份一份做成刺身、炙燒握壽司或親子丼吃掉。腦袋裡的鮭魚蟲全程都有意見。

## 怎麼玩

- **魚缸**：魚卵要待在 4–8°C 的冰水裡，熱了就加冰塊。孵出來以後記得換水、摸摸牠，長成成鮭就能放進大海。
- **河口**：拋竿，浮標沉下去就收竿，按住按鈕收線。同一條掙脫三次會被放生。
- **冷鏈倉**：先進先出。吃不完可以分給蛋撻、哥哥或爸爸。
- **餐桌**：刺身 150 g、炙燒握 120 g、親子丼 180 g 加一點鮭魚卵。
